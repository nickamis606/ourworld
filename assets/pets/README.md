# Pet Sprites

Place optimized pet sprites here.

## Expected Files

- `bubbles.png`  (Pink bear-like pet)
- `milo.png`     (Green cat pet)
- `luna.png`     (Blue pet with star)
- `sprout.png`   (Light green plant pet)
- `pip.png`      (Yellow pet with bow/tuft)
- `nova.png`     (Purple pet with crown)

## Guidelines

- Recommended size: 48x48 or 64x64 pixels
- Use transparent PNG format
- Keep file sizes small for low-power handhelds
- `PetSprite` class will automatically load these when present
- If a sprite is missing, the game falls back to basic procedural drawing
